# moderný obchod

Jednoduchá statická stránka pripravená na [GitHub Pages](https://pages.github.com/).

## Zapnutie GitHub Pages

1. Pushni tento repozitár na GitHub.
2. V repozitári otvor **Settings → Pages**.
3. Pri **Source** zvol **Deploy from a branch**.
4. Branch: `main` (alebo `master`), folder: `/ (root)`.
5. Ulož. Stránka bude na `https://<username>.github.io/obchod/`.
